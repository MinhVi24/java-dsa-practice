# java-dsa-practice

Classic data structures and algorithms in plain Java (no libraries), written while studying LAB211 / DSA.
Each file is self-contained and has a `main` that prints example results.

## Run

```bash
javac -d out src/*.java
java -cp out TwoSum
```
